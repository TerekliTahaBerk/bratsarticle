# Security policy

Report vulnerabilities or accidental disclosure of patient data, credentials,
private paths, or restricted artifacts privately to the repository owner.
Do not open a public issue containing sensitive material.

Supported security fixes target the current main development branch and the
latest tagged release. Research-model performance errors are scientific issues,
but privacy leaks, unsafe path traversal, unguarded test access, malicious
artifact loading, and dependency compromise are security issues.
